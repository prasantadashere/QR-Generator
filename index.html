``` ### You only need to change 2 lines Find: ```javascript const GITHUB_USERNAME = "YOUR_GITHUB_USERNAME"; const GITHUB_REPOSITORY = "YOUR_REPOSITORY_NAME"; ``` For example, if your GitHub URL is: ```text https://github.com/prasanta123/meow-meow-qr-generator ``` use: ```javascript const GITHUB_USERNAME = "prasanta123"; const GITHUB_REPOSITORY = "meow-meow-qr-generator"; ``` Your repository should then look like: ```text meow-meow-qr-generator/ │ ├── index.html │ └── meowColony/ ├── random-name-1.jpg ├── IMG_8293.jpeg ├── cat_XY72.png ├── meow_123.webp ├── DSC_9283.jpg └── ... ~1000 images ``` You **do not need to know any of the image names**. On every refresh: ```text Page loads ↓ GitHub API gets meowColony files ↓ Filters image files ↓ Chooses random image ↓ Displays it ``` **One thing to be aware of:** GitHub's API has a limit on how many directory entries it returns in one request. With ~1,000 images, this approach may not retrieve all of them in a single call. If you want **all 1,000 images reliably**, I can give you a better version that avoids the GitHub API and works cleanly with Vercel.
